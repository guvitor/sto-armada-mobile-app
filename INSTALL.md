# Как установить приложение «СТО Армада Моторс»

Приложение для записи на сервис: каталог услуг с ценами, запись на удобное время (с аккаунтом сайта или без него) и список ваших записей со статусами.

| Платформа | Статус |
|---|---|
| Android 7.0 и новее | Можно установить из файла APK (инструкция ниже) |
| iPhone / iPad | Пока недоступно, готовим публикацию в App Store |

Скоро приложение появится в Google Play. После этого ставить его будет проще: магазин сам проверит файл и будет присылать обновления.

---

## Установка на Android

### 1. Скачайте файл

1. Откройте эту страницу на телефоне.
2. Справа (на телефоне — ниже, под описанием) найдите раздел **Releases** и откройте последний выпуск. Он помечен зелёной меткой **Latest**.
3. В блоке **Assets** нажмите на файл **`sto-armada-<версия>.apk`**, например `sto-armada-1.0.0.apk`. Размер около 55 МБ.

Файлы `Source code (zip)` и `Source code (tar.gz)` скачивать не нужно: это исходный код, а не приложение.

### 2. Разрешите установку из браузера

Android по умолчанию не ставит приложения не из Google Play и попросит разрешение один раз:

1. Откройте скачанный файл: из уведомления о загрузке или в приложении **Файлы → Загрузки**.
2. Если появится сообщение «Установка из этого источника запрещена», нажмите **Настройки**.
3. Включите **Разрешить установку из этого источника** для браузера, через который скачивали файл (Chrome, Яндекс Браузер и т. п.).
4. Вернитесь назад кнопкой «Назад».

Названия пунктов зависят от производителя. Если не нашли, поищите в настройках телефона «Неизвестные приложения» или «Установка неизвестных приложений».

### 3. Установите

1. Нажмите **Установить**.
2. Если Google Play Защита предупредит, что приложение ей неизвестно, нажмите **Подробнее → Всё равно установить**. Предупреждение появляется потому, что приложение пока не опубликовано в Google Play.
3. Когда установка закончится, нажмите **Открыть**. Ярлык «СТО Армада Моторс» появится на рабочем столе.

После установки разрешение для браузера можно выключить обратно (шаг 2, пункт 3).

### 4. Начните пользоваться

- **Записаться без регистрации:** выберите услугу, дату и время, укажите имя и телефон.
- **Войти в аккаунт:** используйте логин и пароль от сайта [sto.armada-motors.com](https://sto.armada-motors.com). Тогда на экране «Мои записи» будет видно, какие записи вы сделали и в каком они статусе.

Приложению нужен интернет, другие разрешения оно не запрашивает.

## Обновление

Скачайте APK последнего выпуска и установите его поверх старой версии, как в шагах 1–3. Удалять старую версию не нужно, вход в аккаунт сохранится.

## Частые проблемы

| Проблема | Что делать |
|---|---|
| «Приложение не установлено» | Проверьте, что на телефоне Android 7.0 или новее и есть хотя бы 150 МБ свободной памяти. Если файл скачался не полностью, скачайте его заново. |
| «Синтаксическая ошибка» / «Ошибка при синтаксическом анализе пакета» | Файл повреждён при загрузке, скачайте его заново. |
| «Конфликт с существующим пакетом» | Удалите установленную версию приложения и поставьте новую. Аккаунт придётся ввести заново. |
| Каталог не загружается | Проверьте интернет, затем закройте приложение и откройте его снова. |
| Не получается войти | Проверьте логин и пароль на сайте. Пароль можно восстановить там же. |
